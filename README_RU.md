# Real Voice AI V4.1 — проект

## Что изменено
- Исправлена сборка GitHub Actions: теперь она собирает именно `app/main.py` как `RealVoiceAI.exe`.
- Установщик использует `installer/RealVoiceAI.iss`, а не старый V3 `.iss`.
- Имя артефакта: `RealVoiceAI-Setup-v4.1`.
- Добавлен выбор активной модели и сохранение выбора между запусками.
- Импорт и загрузка файлов `.pth`, `.onnx`, `.index`.
- Удаление выбранной модели.

## Важно: статус функциональности
Это этап V4.1 менеджера моделей. **Реальное преобразование голоса в реальном времени ещё не реализовано.** Кнопка запуска намеренно отключена. Наличие модели в списке или выбор модели не означает, что она может быть запущена. Для этого требуется подключить RVC inference backend, потоковый аудиоввод/вывод и виртуальное аудиоустройство.

Совместимость модели нельзя определить только по расширению `.pth`/`.onnx`. Не загружайте недоверенные `.pth`: такие файлы могут содержать сериализованные объекты. `.index` — вспомогательный индекс, а не самостоятельная модель.

## Сборка без Python на компьютере пользователя
1. Замени файлы репозитория содержимым этого архива.
2. Открой GitHub → Actions → `Build Real Voice AI V4.1 installer`.
3. Нажми `Run workflow`.
4. После успешного запуска скачай artifact `RealVoiceAI-Setup-v4.1`.

Python используется только на runner GitHub Actions. На компьютере, где запускается готовый установщик, Python не нужен.

## Техническая база для следующего этапа
RVC-Project публикует собственный realtime GUI и описывает потоковое преобразование; их документация указывает ориентир задержки порядка 170 мс, зависящий от аудиодрайверов и оборудования. Для RTX 50-й серии документация текущей ветки указывает отдельный CUDA 12.8 набор зависимостей. Это нужно учесть при упаковке inference backend.
