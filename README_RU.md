# AI Voice Changer RTX — V3

## Что это
V3 — Windows GUI-оболочка с автоматической загрузкой готового CUDA-движка VCClient и встроенным окном его локального интерфейса. Пользователю не нужно отдельно устанавливать Python или VCClient: готовый EXE содержит GUI и при первом запуске скачивает движок.

## Требования
- Windows 10/11 x64
- NVIDIA GPU; для этой конфигурации выбран CUDA-пакет VCClient
- Интернет при первой установке
- Драйвер NVIDIA, актуальный для RTX 5070
- Для Discord/игр потребуется виртуальное аудиоустройство (например, VB-CABLE); его драйвер устанавливается отдельно с подтверждением Windows.

## Сборка EXE
Для разработчика: на Windows установите Python 3.11 и запустите `build_windows.bat`.
Или загрузите проект в GitHub и запустите workflow **Build Windows app**. Windows EXE будет опубликован как artifact.

## Первый запуск
1. Запустите `AIVoiceChangerRTX.exe`.
2. Программа скачает CUDA-сборку из официального каталога VCClient на Hugging Face и распакует её в `%LOCALAPPDATA%\\AIVoiceChangerRTX`.
3. Нажмите «Запустить преобразование». Встроенное окно откроет локальную панель движка.
4. Загрузите RVC-модель, которую вы имеете право использовать, в панели движка и выберите микрофон/виртуальный выход.

## Важные ограничения V3 preview
- Это первый интеграционный preview, не подписанный установщик MSI/Setup.exe.
- Выбор модели, аудиоустройств и точные параметры инференса пока остаются в интерфейсе VCClient, встроенном в окно приложения.
- Каталог загрузок VCClient и состав доступных сборок контролируются upstream-проектом; при изменении структуры Hugging Face может потребоваться обновление загрузчика.
- Не все RVC-модели совместимы со всеми версиями движка. Используйте модели из источников, которым доверяете, и соблюдайте лицензии/согласие на клонирование голоса.

## Сборка установщика Setup.exe (Windows)
1. Установите Inno Setup 6: https://jrsoftware.org/isinfo.php
2. Откройте папку проекта в Windows.
3. Запустите `build_installer_windows.bat`.
4. Готовый установщик появится в `release\\AI-Voice-Changer-RTX-Setup-v3.exe`.

Установщик ставит собранное приложение в Program Files, добавляет пункт меню Пуск и предлагает создать ярлык на рабочем столе. Для автоматической сборки без локальной настройки можно загрузить проект в GitHub и запустить workflow **Build Windows installer**; EXE будет доступен в Artifacts запуска workflow.
