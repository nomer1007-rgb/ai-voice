# Real Voice AI V4 — замена проекта V3

Новый самостоятельный интерфейс и менеджер локальных голосовых моделей для Windows x64.

## Важно: текущий статус

Эта исходная сборка реализует новый интерфейс, импорт/загрузку и каталогизацию файлов моделей. **Нейросетевое преобразование голоса в реальном времени пока не подключено.** Кнопка запуска намеренно отключена: сборка не должна создавать впечатление, что смена голоса уже работает.

Для полноценной версии требуется интеграция inference backend (RVC/совместимый движок), потокового аудио и виртуального микрофона. Совместимость `.pth`/`.onnx` зависит от архитектуры и версии модели; одного расширения файла недостаточно. `.index` — вспомогательный файл для поддерживаемых RVC-моделей.

## Что умеет этот этап

- Новый интерфейс без встроенного окна VCClient.
- Импорт `.pth`, `.onnx`, `.index`.
- Скачивание модели по прямой HTTP(S)-ссылке.
- Локальный каталог `%LOCALAPPDATA%\\RealVoiceAI\\models`.
- Удаление и просмотр добавленных моделей.
- Сборка Windows приложения через GitHub Actions.

## Сборка через GitHub Actions

1. Замени содержимое старого репозитория файлами этого проекта (или загрузи архив и распакуй поверх старого кода).
2. В GitHub открой Actions → Build Windows installer → Run workflow.
3. После успешной сборки скачай artifact `RealVoiceAI-Windows-Installer`.

## Локальная сборка

Нужен Python 3.11 и Inno Setup. Запусти `build_windows.bat`, затем собери установщик командой `iscc installer\\RealVoiceAI.iss`.

## Следующий технический этап

Подключить совместимый RVC backend через документированный API, реализовать потоковый ввод/вывод с низкой задержкой, мониторинг GPU, переключение модели и виртуальный аудиовыход. До завершения этих работ V4 не является готовым voice changer.
