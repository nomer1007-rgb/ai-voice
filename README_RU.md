# Real Voice AI V5 — RVC Real-Time для Windows

V5 сохраняет отдельное окно Real Voice AI для управления моделями и добавляет установку/запуск официального RVC Real-Time backend.

## Что умеет V5
- Импортировать и хранить RVC-модели `.pth` и дополнительные retrieval-файлы `.index`.
- Сохранять выбранную модель в настройках приложения.
- Устанавливать отдельный Python 3.12 runtime в `%LOCALAPPDATA%\RealVoiceAI\engine\runtime`.
- Устанавливать PyTorch 2.7.1 + CUDA 12.8 и зависимости RVC для NVIDIA RTX 50 series.
- Скачивать исходники RVC-Project, обязательные HuBERT/RMVPE pretrained-файлы и запускать `go-realtime_gui.bat`.
- Копировать добавленные `.pth` и `.index` в каталоги RVC перед запуском.

## Первый запуск движка
1. Установи Real Voice AI V5.
2. Импортируй свою совместимую RVC-модель `.pth` (и соответствующий `.index`, если он нужен модели).
3. Нажми **«Установить / обновить движок»**. Нужны интернет и несколько гигабайт свободного места. Не закрывай приложение до завершения установки.
4. Нажми **«Запустить RVC Real-Time»**.
5. В открывшемся окне RVC выбери свою модель, входной микрофон, выходное устройство и параметры F0. Модель должна отображаться в списке RVC.
6. Для Discord/игр выбери виртуальный аудиокабель (например, VB-CABLE) как устройство вывода RVC, а соответствующий виртуальный вход — как микрофон в Discord/игре.

## Совместимость
- Целевая платформа: Windows 10/11 x64.
- GPU: NVIDIA RTX 50 series; установщик движка использует `torch==2.7.1+cu128` и `torchaudio==2.7.1+cu128` согласно текущей инструкции RVC-Project.
- В этой версии поддерживаются RVC `.pth` и `.index`. `.onnx` не подключается.
- CUDA Toolkit отдельно обычно не требуется для CUDA wheel PyTorch; нужен актуальный NVIDIA-драйвер.

## Честное ограничение интеграции
V5 запускает официальный RVC Real-Time GUI в отдельном окне. Это настоящий realtime backend, но выбор аудиоустройств, модели и параметров пока выполняется в окне RVC, а не внутри главного окна Real Voice AI. Успешность работы зависит от совместимости конкретной модели, драйвера, микрофона и аудиоустройств. Перед использованием проверь звук локально.

## Журнал
`%LOCALAPPDATA%\RealVoiceAI\engine-install.log`

## Сборка установщика
GitHub → Actions → **Build Real Voice AI V5 installer** → Run workflow → скачай artifact `RealVoiceAI-Setup-v5`.

## Безопасность
Не загружай неизвестные `.pth`-файлы. Используй модели только из доверенных источников. Само расширение файла не гарантирует совместимость или безопасность.

## Компоненты и лицензии
RVC backend скачивается из [RVC-Project/Retrieval-based-Voice-Conversion-WebUI](https://github.com/RVC-Project/Retrieval-based-Voice-Conversion-WebUI) при установке движка. Ознакомься с лицензией upstream-проекта и лицензиями его зависимостей.


### Исправление V5.1
В V5.1 установочный скрипт `scripts/install_rvc.ps1` дополнительно копируется Inno Setup в `{app}\scripts`, а приложение ищет его как в каталоге PyInstaller, так и рядом с установленной программой. Это исправляет ошибку «Не найден файл install_rvc.ps1».
